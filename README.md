# Hussain Hakimi Portfolio

React + TypeScript portfolio with modular routing, layouts, data, services, and reusable UI components.

## Run locally

```bash
npm install
npm run dev
```

Run `npm run typecheck` and `npm run build` before deploying.

Portfolio content is centralized in `src/data/`. Add certificate PDFs to `public/certificates/` and then assign their paths in `src/data/certifications.ts`.
